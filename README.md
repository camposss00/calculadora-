 Calculadora

Calculadora desenvolvida com HTML, CSS e JavaScript, com uma interface simples e funcional. O projeto permite realizar operações matemáticas básicas e possui recursos para facilitar o uso, como limpeza dos valores e correção de entradas.

O objetivo foi criar uma calculadora prática enquanto aprimoro meus conhecimentos em JavaScript, manipulação do DOM e desenvolvimento de interfaces web.

 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

 Funcionalidades

* Adição, subtração, multiplicação e divisão
* Limpeza dos valores
* Interface responsiva
* Tratamento de entradas e resultados
